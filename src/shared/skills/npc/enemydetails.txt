//Technical details of NPC losing track of a player
//Once player goes out of sight (ex: turned a corner) enemy will save that last spot as the spot where the player is last seen
//Enemy will approach that point trying to look for the player
//They will pick a random walk point out of the 5 points closest to them (on the walkpoint container). this is to simulate investigating
//If they lose sight they will return to default civilian behavior(wandering) until they regain sight of the player.

// 1. The follower
//
// Follows closest player until LOS cant be maintained (unless omniscient, omniscient means the npc keeps following you no matter how you try to hide)
// defaults to walktopoint (complex pathfinding) to navigate to player model
// if close, to save compute time, uses stepTransformTowards (this function makes npcn simply walk directly to the player's spot.)

// 2. The Distancer
//
// Maintains distance between itself and the player while keeping line of sight and maintaining distance
// If player advances they will back up
// If player backs up, they will advance
// If player advances and they're limited by a wall behind them, use escape vector to find another direction to maintain distance
// If vision to player is obscured by wall, they'll pathfind to the player
// - If they are within distance AND have vision, they will stop walking towards the player
// - If they are within distance and dont have vision, continue pathfinding to player
// - If they are outside of distance and have vision, close the gap to maintain distance
// - If they are outside of distance and don't have vision, pathfind until the conditions above are met
// Defaults to civilian behaviors if no players in sight (unless omniscient)
//
// 3. The Stalker
//
// Slowly walks towards the player, trying to be discrete, maintains LOS, "watching you"
// Falls back to normal civilian behavior once they've lost sight of player (unless omniscient = true)
// More or less the same as the follower
//
// 4. Civilian
// Stands around and walks to random points specified on the WalkablePoints
// To avoid clumping, the numbers of npcs on a point is kept track so npcs would prefer to pathfind to empty walkable points. Also add a random offset on the walkpoint everytime a Civilian chooses them so it doesnt look like they're mechanically in one spot
// To avoid duplicate npcs when possible, the outfits are counted and 2 of the same looking characters will only exist once theres 1 instance of every character in the outfits folder
// On the creation of a stimulus (yelling/threats, weapons, gunshots) a civilian will get an increase in alertness depending on the stimulus type.
// On certain alertness levels, civilians have a possibility of persistently pursuing until their alertness stat goes down to below 50 (suspicious), on this state they'll get the behaviors similar to the stalker but with full walkspeed
// On the creation of a sound or visual stimulus, civilians will look at or walk to the source to check on it before getting an increase in alertness
